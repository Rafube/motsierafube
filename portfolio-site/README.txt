Motsie Rafube portfolio site
- index.html  : the whole site (3 pages switched by the # in the address: #home, #project, #experience)
- img/        : the four dashboard screenshots used in the case study
Keep index.html and the img folder together. Open index.html in any browser to preview.
To publish: upload both to any static host (GitHub Pages, Netlify, Cloudflare Pages).
Fonts load from Google Fonts, so an internet connection is needed for the intended typography.

Files: index.html (page content), styles.css (all styling), script.js (filters, tabs, navigation, resume download). Keep them in the same folder as img/ and the resume PDF.
